# Security Policy

## About This Repository

This repository contains bug bounty checklists, real-report case-study breakdowns, and interactive HTML/JS reference pages served via GitHub Pages. It does not run a backend service or process user-submitted data — the security considerations here relate to content accuracy, the integrity of the client-side pages themselves, and avoiding accidental exposure of real personal or credential data in illustrative examples.

## Reporting a Security Concern

If you find something here that could be a genuine security concern, please report it privately rather than opening a public issue. This includes:

- Any real, working credential, API key, or secret accidentally left in a file, script, or commit history
- Any real, personally identifiable information (names, phone numbers, emails, addresses) that shouldn't be public
- Any client-side script (in the interactive HTML pages) that loads from an external source not under my control, or behaves in a way that could affect a visitor's browser beyond simple checklist interactivity
- Any linked report or reference that has been taken down and now points somewhere unexpected or unsafe
- Any broken or misleading link that could redirect to a malicious destination

**To report:** Please open a private security advisory via this repository's **Security** tab ("Report a vulnerability"), or reach out directly via [LinkedIn](https://linkedin.com/in/dheerajkumarjayaswal).

Please do not open a public GitHub issue for sensitive findings — this gives time to review and fix before the detail is public.

## What This Policy Does Not Cover

- Disagreements about a checklist's accuracy or a report's classification (open a regular issue or discussion — happy to hear these)
- Requests to add new checklists or report breakdowns (also fine as a regular issue)
- General questions about the material

## Response

This is a personally maintained repository, not a funded project with an SLA. I'll do my best to respond and address anything genuine as quickly as I reasonably can.
